# DEVNS 1.0.0

DEVNS 1.0.0 is the first public hardening release of the local-first control plane for long-running coding agents.

## What It Solves

Coding agents can now work for much longer than a single human review loop. DEVNS keeps that work tied to:

- approved RFC intent,
- explicit acceptance criteria,
- typed evidence,
- read-only review packets,
- feature-sized commits,
- and morning review reports.

## Highlights

- `devns doctor/init/discover/rfc/run/lanes/evidence/review/complete/stop` command surface.
- JSON workspace under `.devns/` as the agent-readable source of truth.
- RFC clarification gate before a candidate can become executable work.
- Evidence quality gate with verification types such as `command`, `browser_smoke`, `human_review`, and `review_agent`.
- `devns evidence add` and `devns lanes ingest` for review/browser/human evidence without hand-editing JSON.
- Review packets with explicit `--commit` and `--base` support.
- Local dashboard and morning review reports.
- Claude Code and Codex plugin packages.
- CI, Apache-2.0 license, governance docs, and smoke coverage.

## Install

Install from npm:

```sh
npx @kpcure/devns doctor
```

The unscoped `devns` package name on npm belongs to another project. Use the scoped package name `@kpcure/devns`.

## Quick Try

```sh
npx @kpcure/devns init --project-name "Example Project" --project-description "Describe the migration or feature goal."
npx @kpcure/devns discover --json
npx @kpcure/devns run --json
npx @kpcure/devns dashboard
```

- `devns` local entrypoint,
- `.devns/` workspace contract,
- feature/RFC/evidence schemas,
- command lanes,
- review packets,
- completion metadata.

Still evolving:

- richer browser lane templates,
- project-specific policy packs,
